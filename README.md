# Clot // Яшаэдишен

Приложение для сжатия фото и видео с поддержкой интерполяции кадров.

   - 🍏 **[Скачать для Mac OS](https://drive.google.com/open?id=1FrZ1Cnc3HeJTgTxE7_WQlFGZD-BPg0Fc&usp=drive_fs)**

Чтобы включить возможность установки приложений из «Любых источников», выполните следующие действия
1. Откройте Системные настройки.
2. Перейдите в раздел Конфиденциальность и безопасность.
3. Прокрутите страницу вниз до подраздела Безопасность.
4. Найдите пункт «Разрешить использование приложений из:».
5. Выберите вариант «Любых источников» в выпадающем списке
Возможно, для внесения этих изменений потребуется ввести пароль администратора вашего компьютера.

*Все необходимые инструменты (FFmpeg и модуль интерполяции кадров RIFE) уже встроены в программу. Дополнительная ручная настройка не требуется!*

---

## Возможности

-  Сжатие фото (JPEG, PNG, WebP, AVIF)
-  Конвертация и сжатие видео (MP4, MOV, WebM, MKV, AVI)
-  Интерполяция кадров до 120fps (rife-ncnn-vulkan)
-  Автоопределение режима фото/видео
-  Пауза и остановка обработки
-  Неограниченная пакеткая загрузка файлов (хоть тыщу за раз)
