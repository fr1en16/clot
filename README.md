# Clot // Яшаэдишен

Приложение для сжатия фото и видео с поддержкой интерполяции кадров.

## Установка

1. Скачайте необходимый установщик для вашей архитектуры Mac:
   - 🍏 **[Скачать Clot-1.0.0-arm64.pkg (для Apple Silicon M1/M2/M3)](https://drive.google.com/open?id=1FrZ1Cnc3HeJTgTxE7_WQlFGZD-BPg0Fc&usp=drive_fs)**
2. Запустите установщик и следуйте простым инструкциям на экране.
3. Откройте папку **«Программы»** на вашем Mac и запустите **Clot**.

*Все необходимые инструменты (FFmpeg и модуль интерполяции кадров RIFE) уже встроены в программу. Дополнительная ручная настройка не требуется!*

---

## Разработка и сборка из исходников

Если вы хотите собрать проект самостоятельно:

```bash
git clone https://github.com/fr1en16/clot.git
cd clot
npm install
npm run build
```

## Возможности

- 📷 Сжатие фото (JPEG, PNG, WebP, AVIF)
- 🎥 Конвертация и сжатие видео (MP4, MOV, WebM, MKV, AVI)
- 🔄 Интерполяция кадров до 120fps (rife-ncnn-vulkan)
- ⚡ Автоопределение режима фото/видео
- ⏯ Пауза и остановка обработки
