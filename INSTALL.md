# Clot // Яшаэдишен — Инструкция по установке

## Требования

- macOS 11 (Big Sur) или новее
- Node.js 18+ ([скачать](https://nodejs.org))
- npm (устанавливается вместе с Node.js)
- FFmpeg ([скачать](https://ffmpeg.org/download.html) или через Homebrew)
- *(Опционально)* rife-ncnn-vulkan — для интерполяции кадров

---

## 1. Клонирование репозитория

```bash
git clone https://github.com/fr1en16/clot.git
cd clot
```

---

## 2. Установка FFmpeg

### Через Homebrew (рекомендуется):
```bash
# Установить Homebrew (если не установлен):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Установить FFmpeg:
brew install ffmpeg
```

### Вручную:
1. Скачай бинарник с [ffmpeg.org](https://evermeet.cx/ffmpeg/)
2. Распакуй и помести `ffmpeg` в `/usr/local/bin/`
3. Сделай исполняемым: `chmod +x /usr/local/bin/ffmpeg`

Проверка установки:
```bash
ffmpeg -version
```

---

## 3. *(Опционально)* Установка RIFE для интерполяции кадров

Нужен только если хочешь использовать функцию **Интерполяция (FPS)**.

1. Скачай `rife-ncnn-vulkan` для macOS с [GitHub](https://github.com/nihui/rife-ncnn-vulkan/releases)
2. Распакуй архив
3. Помести папку `rife-ncnn-vulkan` в директорию проекта (`clot/rife-ncnn-vulkan/`)

Структура должна выглядеть так:
```
clot/
├── rife-ncnn-vulkan/
│   ├── rife-ncnn-vulkan   (исполняемый файл)
│   └── models/
│       └── rife-v4.6/
│           ├── flownet.bin
│           └── flownet.param
```

---

## 4. Установка зависимостей Node.js

```bash
npm install
```

---

## 5. Запуск приложения

```bash
npm start
```

---

## 6. Сборка `.app` (для распространения)

```bash
npm run dist
```

Готовое приложение появится в папке `dist/`.

> **Примечание:** При первом запуске macOS может показать предупреждение безопасности.  
> Перейди в **Системные настройки → Конфиденциальность и безопасность** и нажми **«Всё равно открыть»**.

---

## Возможные проблемы

| Проблема | Решение |
|---|---|
| `ffmpeg: command not found` | Установи FFmpeg через Homebrew или укажи путь вручную |
| Ошибка при запуске `.app` | Сними карантин: `xattr -cr /path/to/Clot.app` |
| Интерполяция не работает | Проверь наличие папки `rife-ncnn-vulkan` в директории проекта |
| Приложение не открывается | Убедись, что версия macOS 11+ и Node.js 18+ |

---

## Использование

1. Запусти приложение
2. Выбери папку с фото или видео (режим определяется автоматически)
3. Настрой параметры:
   - **Качество** — степень сжатия фото (1–100)
   - **Формат** — целевой формат файла
   - **Интерполяция** — увеличение плавности видео (30/60/90/120 fps)
   - **Сжатие** — включить/отключить перекодирование видео
4. Нажми **Старт**
