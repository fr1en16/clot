# Clot // Яшаэдишен

Приложение для сжатия фото и видео с поддержкой интерполяции кадров.

📖 **[Инструкция по установке](INSTALL.md)**

## Быстрый старт

```bash
git clone https://github.com/fr1en16/clot.git
cd clot
npm install
npm start
```

## Возможности

- 📷 Сжатие фото (JPEG, PNG, WebP, AVIF)
- 🎥 Конвертация и сжатие видео (MP4, MOV, WebM, MKV, AVI)
- 🔄 Интерполяция кадров до 120fps (rife-ncnn-vulkan)
- ⚡ Автоопределение режима фото/видео
- ⏯ Пауза и остановка обработки
